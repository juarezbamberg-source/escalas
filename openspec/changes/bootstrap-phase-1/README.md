# bootstrap-phase-1

Base inicial do produto a partir do PRD/TRD e ADRs ja definidos.

## Why

O projeto ainda nao possui a base executavel do sistema de escala. Esta mudanca transforma os requisitos ja definidos em um pacote OpenSpec pronto para implementacao, reduzindo ambiguidade antes do codigo.

## What Changes

- Define a fase 1 do produto com backend FastAPI e banco relacional.
- Introduz tres capacidades iniciais: cadastros-base, gestao-escala e visualizacao-calendario.
- Organiza o trabalho em proposta, design e tarefas verificaveis.
